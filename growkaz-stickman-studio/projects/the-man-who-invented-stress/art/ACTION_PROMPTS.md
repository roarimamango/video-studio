# Action clips for Kling / Hailuo (image-to-video)

**How to make each clip**
1. Upload the image from `raw/` as the **start frame**.
2. Paste the prompt. Set **5 s**, **16:9**, and the lowest "creativity / motion strength" that still moves (Kling: about 0.5).
3. Paste the **negative prompt** (Kling has a field for it; Hailuo doesn't, so skip it there).
4. Make 2 takes and keep the one that stays most like a drawing.
5. Save the file as `action/<shot id>.mp4`, e.g. `action/12_selye_chase.mp4`.

**Negative prompt (every clip):**
`3d render, photorealistic, smooth shading, morphing face, extra limbs, flicker, camera shake, text`

Every prompt starts with the same style lock, so the clips match the stills:
`Hand-drawn ink and watercolor animation, rough sketch lines, white paper background, limited animation.`
